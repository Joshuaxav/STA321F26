The data set used in this project is the “hsb2” data set, an acronym for “high school and beyond”. The data set contains 200 randomly selected observations from the “High School and Beyond” survey, which was conducted by the National Center for Education Statistics and polled seniors in high school. The dataset uses 11 total variables, 1 identifying variable (id), 5 numerical variables, including the response variable write, and 5 categorical variables.

The dataset contains enough information to investigate these questions because it includes socioeconomic status, academic program, demographic characteristics, and multiple standardized test scores for 200 students, with 11 variables. This allows us to compare academic preformance across different groups and use statistical methods to determine whether a meaningful relationships exist.

Practical Question

Using this data set, we hope to find whether a students socioeconomic status and academic program relate with their preformance in highschool. Analytically, we would like to see whether there is a statistically significant relationship between socioeconomic status and a students standardized writing scores. we would also like to see whether writing scores can be predicted using socioeconomic status or other test scores.

If a transformation is needed, we would transform the response variable. This is because the Box Cox transformation helps fix stabilize variance, normalize residuals, and improves linearity, which are tied to the response variable in a linear regression model.

Residual Plots

We can see from the residual plots:

  • The Residuals Vs Fitted plot has points randomly scattered points, but a bent line possibly indicating a linearity violation.

  • The Scale-Location plot, similar to the vs fitted plot, has points scattered randomly, but a bent line possibly indicating the constant variance assumption is not satisfied

  • The QQ Residual plot shows departures from the red line near both tails, suggesting a violation of the normality assumption.

  • The Residuals Vs Leverage plot indicates that there are no serious outliers,

From the SLR model, we see a positive relationship between reading and writing scores, with a reading coefficient of 0.55. This means that for every one point increase in reading score, the predicted writing score increases by about 0.55 points. The R² value is 0.356, meaning that reading scores explain about 35.6% of the variation in writing scores. The p-value for reading is less than 2.2 × 10⁻¹⁶, providing very strong evidence of a statistically significant relationship between reading and writing scores.

Box Cox Transformation

Since the residual plots show possible violations, we check if transformations would fix the problems to a meaningfull degree.

boxcox(lm(write ~ reading, data = hsb2), lambda = seq(1, 3, 1/10))

Box-Cox transformation. 

lambda <- 2.3
write.bc <- (write^lambda - 1) / lambda
boxcox.m <- lm(write.bc ~ reading)
par(mfrow = c(2, 2))
plot(boxcox.m)

Box-Cox transformed SLR. 

compare_table <- tibble(

The transformed model only shows small improvement with the R² rising slightly from 0.356 to 0.367. The p-value for residual normality also rises from 0.007 to 0.039. Despite this, The residual plots still show violations after transformation. The Residuals Vs Fitted plot has a bent line possibly indicating a linearity violation. The Scale-Location plot has a bent line indicating constant variance is not satisfied. Along with this, the QQ Residual plot shows departures from line near both tails, suggesting a violation of the normality assumption. Therefore, we choose not to transform and stick with the model in its original scale, write ~ read.

Bootstrap confidence intervals

B <- 5000
vec.id <- 1:length(write)

boot.beta0 <- NULL
boot.beta1 <- NULL

for(i in 1:B){
  boot.id <- sample(vec.id, length(write), replace = TRUE)
  
  boot.reg <- lm(write[boot.id] ~ reading[boot.id])
  
  boot.beta0[i] <- coef(boot.reg)[1]
  boot.beta1[i] <- coef(boot.reg)[2]
}

boot.beta0.ci <- quantile(boot.beta0, c(0.025, 0.975), type = 2)
boot.beta1.ci <- quantile(boot.beta1, c(0.025, 0.975), type = 2)

boot.coef <- data.frame(
  Intercept = boot.beta0.ci,
  Reading = boot.beta1.ci
)

rownames(boot.coef) <- c("2.5%", "97.5%")

pander(boot.coef,
       caption = "95% Bootstrap Confidence Intervals for Regression Coefficients")
95% Bootstrap Confidence Intervals for Regression Coefficients
  Intercept Reading
2.5% 18.94 0.463
97.5% 29.05 0.6432

The bootstrap confidence interval for the reading coefficient is (0.464 to 0.644). Because this interval does not contain zero, it provides strong evidence that reading score is related to writing score. This agrees with the ordinary least squares regression, which produced a p-value = 2.2 × 10⁻¹⁶. The bootstrap confidence interval also provides a useful check because the residual diagnostics showed some possible violations of the regression assumptions. I would report the bootstrap confidence interval along with the raw regression results because it provides an additional, less assumption-dependent measure of uncertainty for the regression coefficient.
